# Release 8.2.0 – Inventario QR y Transferencias concurrentes

## Resumen

Esta versión incluye **Feature 1** (Inventario QR con control de concurrencia) y **Feature 2** (Transferencias de activos con bloqueo pesimista `SELECT FOR UPDATE`).

- **Inventario QR**: nuevos endpoints de escaneo y registro de inventario, modelo `InventoryRecord` con restricción `@@unique([campaignId, assetId])` y migración `20261023000001_feat_f2_transfer_fk_asset`.
- **Transferencias**: refactor de `TransferAssetService` usando `prisma.$transaction()` y `SELECT FOR UPDATE` para prevenir race conditions, FK `Transfer.assetId → Asset.id` añadida en el esquema Prisma.
- **OpenAPI**: decoradores `@ApiTags`, `@ApiOperation`, `@ApiResponse`, `@ApiParam` en todos los endpoints del controlador `TransferAssetController` y documentación completa disponible en `openapi.json`.
- **Módulo de Inventario**: registro de `InventoryScanController`, `RegisterInventoryScanUseCase` y sus adapters.
- **Pruebas**: se actualizó la suite para cubrir los nuevos flujos y la integridad transaccional.

## Referencias
- Issue: https://github.com/ActFijos/Activa360/issues/2
- FSD: UC‑TRANS‑001 (Transferencias concurrentes)
- Documentación OpenAPI generada en `openapi.json`.

## Instalación
```bash
npm install
npx prisma migrate deploy   # aplica la migración del FK
npm run start:dev          # arranca la API
```

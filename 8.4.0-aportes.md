# Release 8.4.0 – Demo 4: Trazabilidad Integral, Observabilidad y Bajas SABS

## Resumen Ejecutivo

Esta versión consolida la **Demo 4 (Evaluación Final)** de Activa360, integrando la solución completa de gestión de activos fijos institucionales bajo normativa boliviana (D.S. 24051 y D.S. 0181 SABS), con contratos OpenAPI actualizados y observabilidad mediante OpenTelemetry y k6.

---

## Aportes por Integrante (Factor de Aporte Individual)

### 1. Guillermo Omar Daza Alcalá
* **Sincronización Offline (FSD-UC-002):** Implementación del endpoint `POST /activos/sync` con algoritmo de resolución de conflictos por timestamp (*Last Write Wins - LWW*), verificación atómica del lote, actualización geoespacial en `Asset` y registro histórico en `Movement`.
* **Inventario QR y Verificación en Campo (FSD-UC-001):** Endpoints `POST /inventory/scan` y `GET /activos/qr/{qrCode}` con control de concurrencia en base de datos (`@@unique([campaignId, assetId])`).
* **Pruebas de Carga y Percentiles (k6):** Ejecución y reporte del percentil 95 (p95 < 9 ms en operaciones transaccionales) bajo modelo abierto a 30 req/s.

### 2. Josefina Rojas
* **Workflow de Bajas SABS (FSD-UC-003):** Gestión del flujo normativo de bajas bajo D.S. 0181 con control de rol institucional (Jefe de Activos), obligatoriedad de causales y evidencia documental (`POST /bajas`, `GET /bajas`, `POST /bajas/{id}/aprobar`).
* **Restauración Técnica de Estado (FSD-UC-003):** Endpoint `POST /bajas/{id}/rechazar` con evaluación de peritaje técnico en `MaintenanceReport` para restaurar con precisión el estado operativo original (`Dañado` u `Obsoleto`).
* **Interfaz de Usuario Frontend:** Integración y soporte en la vista de Bajas (`frontend/src/pages/Bajas.tsx`).

### 3. Rita Nina
* **Asignación a Custodio (FSD-UC-004):** Formalización de custodia patrimonial mediante `POST /activos/asignar`, `GET /activos/asignaciones` y consulta de nómina `GET /activos/empleados`, persistiendo actas en `AssignmentRecord`.
* **Transferencias Concurrentes (FSD-UC-005):** Endpoints `POST /activos/transferir` y `POST /activos/transferencias/{id}/aprobar` con bloqueo pesimista `SELECT FOR UPDATE` mediante transacciones Prisma.
* **Interfaz de Usuario Frontend:** Integración y soporte en la vista de Asignaciones (`frontend/src/pages/Asignacion.tsx`).

## Contrato OpenAPI y Observabilidad

* **Contrato OpenAPI v8.4.0:** Exportado automáticamente desde NestJS (`npm run openapi:export`) con 31 endpoints documentados y validados contra el linter Spectral en [`openapi.json`](openapi.json).
* **Observabilidad OpenTelemetry & Tempo:** Instrumentación de trazas distribuidas y análisis del cuello de botella en la persistencia de base de datos PostgreSQL/Prisma (85% del tiempo en I/O y transacciones ACID).
* **Documento Técnico de la Demo 4:** [`docs/demos/demo-4.md`](docs/demos/demo-4.md).

## Instalación y Verificación

```bash
# 1. Instalar dependencias
npm install

# 2. Desplegar base de datos y migraciones
docker compose up -d postgres
npx prisma migrate deploy

# 3. Exportar y verificar contrato OpenAPI
npm run openapi:export

# 4. Compilar y arrancar la API
npm run build
npm run start:dev
```
